## 📌 Deskripsi Praktikum

Praktikum 4 merupakan kegiatan pembelajaran Pemrograman Web yang membahas tentang penggunaan CSS untuk mengatur tata letak (layout) halaman website.

Pada praktikum ini, mahasiswa mempelajari cara membuat elemen kotak menggunakan HTML dan CSS, mengatur posisi elemen, membuat navigasi, serta menyusun bagian-bagian halaman website seperti header, hero section, main content, sidebar, dan footer.

Project ini dibuat menggunakan HTML5 dan CSS3 dengan bantuan Visual Studio Code sebagai editor kode.

## 🎯 Tujuan Praktikum

Tujuan dari praktikum ini adalah:

1. Memahami struktur dasar dokumen HTML.
2. Memahami penggunaan CSS untuk mengatur tampilan halaman website.
3. Mempelajari penggunaan properti `float` dan `clear` pada CSS.
4. Membuat dan mengatur elemen kotak (box element).
5. Membuat navigasi menu pada halaman website.
6. Memahami penggunaan elemen header, hero, main content, sidebar, dan footer.
7. Mengatur warna, ukuran, jarak, dan posisi elemen menggunakan CSS.
8. Menghubungkan file HTML dengan file CSS eksternal.

## 🛠️ Teknologi yang Digunakan

- **HTML5** — digunakan untuk membuat struktur halaman website.
- **CSS3** — digunakan untuk mengatur desain dan tata letak website.
- **Visual Studio Code** — digunakan sebagai editor untuk menulis kode program.
- **Web Browser** — digunakan untuk menjalankan dan melihat hasil halaman website.

## 📖 Materi Praktikum

### 1. Box Element

Box element merupakan latihan untuk memahami cara membuat beberapa kotak menggunakan elemen HTML dan mengatur tampilannya menggunakan CSS.

Pada bagian ini, mahasiswa mempelajari:

- Penggunaan elemen `<div>`.
- Pemberian warna latar belakang pada kotak.
- Penggunaan properti `float`.
- Penggunaan properti `clear`.
- Pengaturan jarak menggunakan `padding`.

### 2. Layout Sederhana

Pada bagian ini, mahasiswa membuat halaman website sederhana menggunakan struktur HTML dan CSS.

Komponen layout yang dipelajari meliputi:

- **Header:** bagian atas halaman yang berisi judul website.
- **Navigation:** bagian menu yang digunakan untuk navigasi halaman.
- **Hero Section:** area untuk menampilkan banner atau gambar utama.
- **Main Content:** bagian yang menampilkan konten utama website.
- **Sidebar:** bagian samping untuk menampilkan informasi tambahan.
- **Footer:** bagian bawah halaman website.

### 3. CSS Navigation

Navigasi dibuat menggunakan elemen HTML `<nav>` dan tautan `<a>`.

CSS digunakan untuk mengatur warna latar belakang menu, warna teks, ukuran tulisan, jarak antar elemen, serta tampilan ketika menu aktif atau kursor diarahkan ke menu.

### 4. CSS Layout

CSS digunakan untuk mengatur posisi dan ukuran elemen agar halaman website terlihat lebih terstruktur.

Beberapa properti yang digunakan antara lain:

- `width` untuk mengatur lebar elemen.
- `margin` untuk mengatur jarak luar elemen.
- `padding` untuk mengatur jarak dalam elemen.
- `background-color` untuk memberikan warna latar belakang.
- `display` untuk mengatur cara elemen ditampilkan.
- `float` untuk mengatur elemen mengambang.
- `clear` untuk mengatur perilaku elemen terhadap elemen yang menggunakan `float`.

## 💻 Cara Menjalankan Project

1. Download atau clone repository dari GitHub ke komputer.
2. Buka Visual Studio Code.
3. Pilih **File → Open Folder**.
4. Pilih folder `Praktikum4`.
5. Buka file `lab4_box.html` untuk menjalankan latihan Box Element.
6. Buka file `lab4_layout/home.html` untuk melihat halaman layout sederhana.
7. Jalankan file HTML menggunakan browser, misalnya Google Chrome atau Safari.
8. Jika terdapat perubahan pada kode, simpan file menggunakan `Command + S`, lalu refresh halaman browser.
